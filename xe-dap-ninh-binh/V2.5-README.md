# XE DAP NINH BINH V2.5 – AI SEO Importer

V2.5 adds a separate AI SEO importer module for safe testing before integrating it into the main importer.

## Current features
- Analyze a public product URL.
- Extract product title, price, page text and product images.
- Send source data to OpenAI Responses API.
- Generate Vietnamese SEO title, meta description, short description and product description.
- Preserve source facts and instruct the model not to invent specifications.
- Create WooCommerce products as **Draft** only.
- Store source URL and generated SEO metadata.

## Important
This module is intentionally separate from the production importer while variation handling is being tested. Do not bulk-import products yet.

Recommended test flow:
1. Activate `xe-dap-ninh-binh-ai-v2.5.php`.
2. Enter OpenAI API key.
3. Test one Thống Nhất product URL.
4. Review the generated draft.
5. Only after the result is correct should the module be merged into the main importer.
